# 测试问题与参考答案

本页对应仓库根目录的 [`test.sql`](../test.sql)。先完成 Alembic 迁移，再通过 VS Code 的 MySQL 插件连接本机 `127.0.0.1:3307`、数据库 `aiden`，执行整个 SQL 文件。脚本向 15 张应用表写入固定 ID 的演示数据；`alembic_version` 是迁移管理表，不应手工插入测试行。重复执行脚本不会修改已有的同 ID 测试行。

前端可使用 `sql.customer@aiden.test` / `aiden123` 登录。以下时间均为数据库保存的 **UTC 时间**。所有订单、政策和回复都是虚构测试数据。

**当前前端实际表现：** Agent 目前只把 MySQL 用于登录、会话和消息保存，还没有接入订单、物流、售后、FAQ 或政策查询工具。因此，直接在聊天框提问上述业务问题时，它不会读取这些测试行；订单、物流、退货和政策问题会得到“当前无法核实”的说明。表中的参考答案用于在数据库中核对数据，以及后续接入查询工具时对照结果。

# 测试问题与参考答案

本页对应 [`sql/test.sql`](../sql/test.sql)。先完成 Alembic 迁移，再通过 VS Code 的 MySQL 插件连接本机 `127.0.0.1:3307`、数据库 `aiden`，执行整个 SQL 文件。脚本向 15 张应用表写入固定 ID 的演示数据；`alembic_version` 是迁移管理表，不应手工插入测试行。重复执行脚本不会修改已有的同 ID 测试行。

前端可使用 `sql.customer@aiden.test` / `aiden123` 登录。以下时间均为数据库保存的 **UTC 时间**。所有订单、政策和回复都是虚构测试数据。

| 可以输入的问题 | 第一版工具 | `test.sql` 中的参考数据 | 主要数据表 |
| --- | --- | --- | --- |

| 订单 `TEST-20260922-001` 的物流到哪了？ | `query_logistics` | 顺丰速运，运单号 `SFTEST20260922001`；最新节点是 2026-09-24 08:15 到达杭州转运中心，包裹状态 `in_transit`。 | `orders`、`shipments`、`tracking_events` |

**当前工具行为：** remote 模式下，客服 Agent 已绑定订单、物流和 FAQ 只读工具。登录用户查询订单和物流时，返回的是当前数据库中属于该用户的记录；FAQ 查询来自启用中的 FAQ 行。若先导入 `sql/test.sql`，测试账号会查到上表中的测试记录；工具代码没有内置这些订单、轨迹或答案。没有匹配记录时工具返回空结果，模型应据实说明。

售后申请、政策表和工单目前没有对应查询工具。`search_faq` 只读取 FAQ，不能用 `policies` 或 `after_sale_requests` 表中的测试行补答；FAQ 未提供依据时，客服必须说明当前无法核实。关于工具参数、权限和 SSE 的说明见 [`tools.md`](tools.md)。

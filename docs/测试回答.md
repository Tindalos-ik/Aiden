## 知识咨询范围与历史演示素材

`search_faq` 检索 `knowledge_chunks`，支持范围取决于**实际按基线导入、向量化且有效的内容**，不是 FAQ/政策表或知识目录中“文件存在”就可回答。下面退货政策、售后手册及旧召回统计是历史演示素材，**不在本轮新基线的默认导入清单内，不是当前正式商城政策或在线验收结果**；商品知识按基线准备后验收，测试 FAQ 仅在独立可选审核导入后验收。

### 前置条件

按 [`本地启动基线`](../frontend/README.md#本地启动) 准备独立演示库与新命名集合，唯一 Markdown 输入通过 `import-markdown --directory ./knowledge --pattern '商品FAQ.md'` 精确导入（该命令没有 `--file`），随后 `vectorize` 并核对统计。不要运行全量导入，也不要把旧库重导入理解为自动重置已有 `vectorized` 状态。`import-faq` 会扫描所有 active FAQ，只在审阅其输入后作为独立可选阶段执行。

新基线采用 `BAAI/bge-small-zh-v1.5`、512 维、`max_seq_length=512` 和新集合 `knowledge_demo_bge_small_512`，不是将原 `knowledge_bm25` 直接改名；Milvus、embedding 和配置所需 reranker 必须可用且维度一致。BGE-M3 / 1024 是另一套示例方案，不是本基线配置。服务故障会返回明确错误，不退回关键词检索；过去“四份文档 + 两行 FAQ”的评估只对应当时素材，不是新基线输入。
